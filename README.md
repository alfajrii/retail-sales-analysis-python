# retail-sales-analysis-python
Retail sales and customer transaction analysis using Python, Pandas, and Matplotlib, including data cleaning, filtering, merging, outlier detection, pivot tables, and data visualization.
# Retail Sales & Customer Transaction Analysis

## Project Overview

This project analyzes retail sales and customer transaction data using Python to identify purchasing patterns, delivery behavior, discount usage, geographic revenue performance, and revenue differences across sales channels.

The analysis was conducted using Python in Google Colab as part of a Data Analyst learning project.
## Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab
